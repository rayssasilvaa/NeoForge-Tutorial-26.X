# Minecraft NeoForge Mod

## Português (Brasil)

Projeto de estudos voltado ao desenvolvimento de mods para Minecraft utilizando **Java** e **NeoForge**.

Este projeto está sendo desenvolvido como prática de programação e acompanhamento de uma série de tutoriais sobre desenvolvimento de mods para Minecraft.

### Tutorial

O projeto acompanha a playlist de tutoriais do Kaupenjoe:

[NeoForge Modding Tutorial](https://youtube.com/playlist?list=PLKGarocXCE1FMoAF23TXkprPCuKmAdcTg)

### Objetivos

* Praticar programação em Java.
* Aprender os fundamentos do desenvolvimento de mods para Minecraft.
* Conhecer a API e os recursos do NeoForge.
* Praticar organização de projetos Java.
* Utilizar Gradle para gerenciamento e build do projeto.
* Utilizar Git e GitHub para versionamento do código.
* Desenvolver funcionalidades próprias conforme o aprendizado evolui.

### Observação

Este é um projeto de aprendizado. Parte da implementação é desenvolvida acompanhando os conceitos apresentados no tutorial indicado acima.

Conforme o projeto evoluir, novas funcionalidades e modificações próprias poderão ser adicionadas.

## English (United States)

Study project focused on Minecraft mod development using **Java** and **NeoForge**.

This project is being developed as a programming practice project while following a tutorial series about Minecraft mod development.

### Tutorial

This project follows Kaupenjoe's tutorial playlist:

[NeoForge Modding Tutorial](https://youtube.com/playlist?list=PLKGarocXCE1FMoAF23TXkprPCuKmAdcTg)

### Goals

* Practice Java programming.
* Learn the fundamentals of Minecraft mod development.
* Learn how to work with the NeoForge API and its features.
* Practice Java project organization.
* Use Gradle for project management and builds.
* Use Git and GitHub for version control.
* Develop custom features as the learning process progresses.

### Note

This is a learning project. Part of the implementation is developed by following the concepts presented in the tutorial linked above.

As the project evolves, additional custom features and modifications may be added.
